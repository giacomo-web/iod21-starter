# Privacy · IOD21 Starter

**English.** IOD21 Starter is a set of plain-text instructions (skills and one command) for Claude. It contains no code that runs on its own, no hooks, no MCP servers, no analytics and no network calls. IOD21 S.r.l. receives no data from it.

- What it does: when you ask, Claude reads and writes Markdown files in the folder you work in (`CLAUDE.md`, `STATO.md`, `memory/`, `recap/`). Those files stay on your computer.
- What it never does: send emails or messages, publish anything, or upload your files anywhere. Email replies are drafts that wait for your ok.
- What Claude itself processes: the text you share in the conversation and the files Claude reads are processed by Anthropic under the terms of your Claude plan, as with any other Claude conversation.
- The skills tell Claude not to store passwords, codes, IBANs or other people's personal data in these files.

Questions: information@iod21.com

**Italiano.** IOD21 Starter è un insieme di istruzioni in testo semplice (skill e un comando) per Claude. Non contiene codice che parte da solo, hook, server MCP, statistiche o chiamate di rete. IOD21 S.r.l. non riceve nessun dato.

- Cosa fa: quando glielo chiedi, Claude legge e scrive file Markdown nella cartella in cui lavori (`CLAUDE.md`, `STATO.md`, `memory/`, `recap/`). I file restano sul tuo computer.
- Cosa non fa mai: inviare email o messaggi, pubblicare, caricare i tuoi file da qualche parte. Le risposte alle email sono bozze che aspettano il tuo ok.
- Cosa elabora Claude: il testo che scrivi nella conversazione e i file che Claude legge sono elaborati da Anthropic secondo i termini del tuo piano Claude, come in ogni altra conversazione.
- Le skill dicono a Claude di non salvare in questi file password, codici, IBAN o dati personali di altre persone.
